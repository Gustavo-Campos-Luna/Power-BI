# Financial Analysis Report

Dashboard de Power BI que resume ventas, órdenes, utilidad y descuentos de una
cadena de tiendas ficticia (datos de práctica, no reales), con desglose por
país, segmento de cliente y producto.

## Qué muestra

- **KPIs principales** (año actual vs. año anterior): ventas, órdenes,
  utilidad, margen de utilidad, descuento total.
- **Órdenes y margen por país** (Canadá, Francia, EE.UU., México, Alemania).
- **Margen de utilidad por segmento de cliente** (Channel Partner, Midmarket,
  Government, Small Business, Enterprise) — Enterprise aparece con margen
  negativo (-3,1 %), la única línea en rojo.
- **Distribución de descuentos** por banda (Alta/Media/Baja).
- **Ventas mensuales** en el tiempo y **top 3 productos** por volumen de venta.
- **Tabla cruzada** de margen por segmento y producto.

Vista completa: [Financial Analysis Report.pdf](Financial%20Analysis%20Report.pdf)
(exportado desde Power BI Desktop).

## Origen

Proyecto guiado por un tutorial de YouTube, hecho para practicar Power BI —
DAX básico, modelado de KPIs con comparación año contra año, y layout de
dashboard ejecutivo.
